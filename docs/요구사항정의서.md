## 4. 요구사항 상세

### REQ-4 아침 일괄 등록

| 항목 | 내용 |
|---|---|
| 분류 / 우선순위 | 기능 / 필수 |
| 설명 | 아침에 그날 할 일을 한 번에 올린다 |
| 처리 조건 · 규칙 | 한 줄 = 한 건. 빈 줄과 앞뒤 공백은 무시한다. 줄 앞의 `-`, `*`, `1.` 같은 목록 기호는 지운다. 등록 날짜 기본값은 선택된 날짜(앱 실행 시 오늘), 우선순위 기본값은 보통, 상태는 대기 |
| 입력 / 출력 | 입력: 여러 줄 텍스트, 날짜 / 출력: 등록된 할 일 목록 |
| 예외 상황 | 유효한 줄이 0건이면 등록하지 않고 안내한다. 한 줄이 200자를 넘으면 해당 줄을 표시하고 등록을 막는다 |
| 수용 기준 | 10줄을 붙여넣으면 10건이 입력 순서대로 오늘 목록 끝에 추가된다 |
| 충족 방안 | SCR-03, API-05 |

### REQ-5 우선순위 지정

| 항목 | 내용 |
|---|---|
| 분류 / 우선순위 | 기능 / 필수 |
| 설명 | 할 일마다 우선순위 등급을 정하고, 같은 날짜 안에서 처리 순서를 정한다 |
| 처리 조건 · 규칙 | 등급: 높음 / 보통 / 낮음. 목록 정렬: 등급(높음→낮음) → 사용자 순서(`sort_order`). 드래그는 같은 등급 안에서만 순서를 바꾼다 |
| 입력 / 출력 | 입력: 등급, 순서 / 출력: 정렬된 목록 |
| 예외 상황 | 완료·취소·연기 항목은 목록 아래쪽 "처리됨" 묶음으로 내린다 |
| 수용 기준 | 등급을 바꾸면 목록이 즉시 다시 정렬되고, 앱을 다시 열어도 순서가 유지된다 |
| 충족 방안 | SCR-01, SCR-02, API-03, API-06 |

### REQ-6 상태값 관리

| 항목 | 내용 |
|---|---|
| 분류 / 우선순위 | 기능 / 필수 |
| 설명 | 할 일의 진행 상태를 5단계로 관리하고 변경 이력을 남긴다 |
| 처리 조건 · 규칙 | 상태: 대기(기본) / 진행 / 완료 / 연기 / 취소. 연기·취소로 바꿀 때는 사유가 필수다. 모든 상태 변경은 이전 상태, 새 상태, 사유, 시각을 이력으로 남긴다 |
| 입력 / 출력 | 입력: 새 상태, 사유 / 출력: 바뀐 상태, 이력 |
| 예외 상황 | 연기된 원본 할 일은 상태를 다시 바꿀 수 없다 (새 날짜에 생긴 할 일에서 처리) |
| 수용 기준 | 상태를 바꾸면 목록 표시와 이력이 함께 바뀐다 |
| 충족 방안 | SCR-01, API-07, API-08 |

### REQ-7 완료 여부 체크

| 항목 | 내용 |
|---|---|

| 수용 기준 | 체크 후 0.5초 안에 완료 표시(취소선)가 보인다 (추정) |
| 충족 방안 | SCR-01, API-07 |

### REQ-8 연기 처리 (사유·연기 날짜)

| 항목 | 내용 |
|---|---|
| 분류 / 우선순위 | 기능 / 필수 |
| 설명 | 오늘 못 한 일을 사유와 함께 다른 날짜로 미룬다 |
| 처리 조건 · 규칙 | 원본 할 일은 상태 연기 + 사유로 원래 날짜에 남는다(통계에 연기로 집계). 새 날짜에 같은 제목·우선순위·태그로 새 할 일을 대기 상태로 만들고 원본을 가리킨다(`postponed_from_id`). 새 할 일에는 "연기됨 (원래 날짜)" 표시를 붙인다 |
| 입력 / 출력 | 입력: 사유(필수), 연기 날짜(필수) / 출력: 원본 상태 변경, 새 할 일 |
| 예외 상황 | 연기 날짜는 원래 날짜보다 뒤여야 한다. 사유 미입력 시 저장하지 않는다 |
| 수용 기준 | 10/26 할 일을 10/28로 연기하면 10/26 목록에는 "연기" 상태로, 10/28 목록에는 "연기됨(10/26)" 표시로 나타난다 |
| 충족 방안 | SCR-04, SCR-01, API-07 |

### REQ-12 주간 통계

| 항목 | 내용 |
|---|---|
| 분류 / 우선순위 | 기능 / 필수 |
| 설명 | 한 주의 결과를 상태별로 본다 |
| 처리 조건 · 규칙 | 한 주 = 월~일 (추정). 집계 기준은 할 일의 날짜(`task_date`). 완료율 = 완료 / (전체 − 취소) (추정, 확인 필요). 요일별 상태 건수 막대그래프, 연기 사유 목록, 취소 사유 목록을 함께 보여준다 |
| 입력 / 출력 | 입력: 주 시작일 / 출력: 상태별 건수, 완료율, 요일별 건수, 사유 목록 |
| 예외 상황 | 할 일이 없는 주는 빈 상태 안내 |
| 수용 기준 | 이번 주 목록의 상태별 건수 합계와 통계 화면 숫자가 일치한다 |
| 충족 방안 | SCR-06, API-10 |

### REQ-17 공유

| 처리 조건 · 규칙 | 대상: 하루 목록(SCR-01) 또는 주간 통계(SCR-06). 형식: 텍스트 / 이미지 중 선택. 텍스트는 클립보드 복사, 이미지는 클립보드 복사 또는 PNG 파일 저장. 텍스트 형식: 날짜 제목 + 상태 기호(☑ 완료, ☐ 대기·진행, ⤳ 연기, ✕ 취소) + 제목 + 연기·취소 사유 |
| 입력 / 출력 | 입력: 대상, 형식, 내보낼 곳 / 출력: 클립보드 내용 또는 PNG 파일 |
| 예외 상황 | 할 일이 없는 날짜·주는 공유 버튼을 비활성화한다. 파일 저장 대화상자를 닫으면 아무것도 하지 않는다 |
| 수용 기준 | 텍스트를 복사해 메모장에 붙여넣으면 화면 목록과 같은 순서·상태로 보인다. 이미지는 화면의 목록·통계 영역과 같은 모양이다 |
| 충족 방안 | SCR-08, API-20 |
